# 校园低碳行为管理系统

求职展示用可运行源码包，内容以当前工作区实际代码为准。项目围绕校园低碳打卡、AI 图片核验、积分与称号、排行榜、异常复核和数据看板展开，包含 Vue 前端、Spring Boot 后端、Flask AI 服务及 MySQL 数据库脚本。

## 运行环境

- JDK 17、Maven 3.6+
- Node.js 18+（推荐使用当前 LTS）、npm 9+
- Python 3.10+、pip
- MySQL 8.0+
- Windows、macOS 或 Linux 均可，以下命令请使用解压目录的实际绝对路径

## 1. 初始化数据库

先启动 MySQL，使用其命令行客户端依次执行：

```bash
mysql -u root -p < "解压目录的绝对路径/sql数据库/schema.sql"
mysql -u root -p < "解压目录的绝对路径/sql数据库/导入数据.sql"
```

第一条命令创建数据表及场景、称号、勋章等公共配置；第二条生成虚构的演示用户和业务数据，用于展示各页面。它会清空并重建本项目专用数据库，不要在已有同名数据库上执行。演示账号密码仅用于本地展示，不是真实账号。

## 2. 配置本地凭据

展示包未包含原开发环境的密码、服务密钥或账号数据。启动前请设置自己的环境变量：

| 环境变量 | 用途 |
| --- | --- |
| `DB_USERNAME` | MySQL 用户名，默认 `root` |
| `DB_PASSWORD` | MySQL 密码 |
| `JWT_SECRET` | 本地 JWT 签名密钥，至少 32 字节随机字符串 |
| `BAIDU_MAP_API_KEY` | 后端百度地图服务密钥，仅定位相关功能需要 |
| `VITE_BAIDU_MAP_API_KEY` | 前端百度地图浏览器密钥，仅地图展示需要 |
| `ZHIPU_API_KEY` | 智谱 AI 服务密钥，智能问答及 AI 视觉审核需要 |

数据库连接地址等公共运行配置保留在后端配置文件中。版本号仍为前后端各自的 `1.0.0`；当前工作区没有独立的更新公告、授权数据或公共校验配置文件，因此展示包未虚构这些内容。系统通知的业务代码与数据表、场景公共校验配置及数据库初始化数据均保留。

## 3. 启动后端

前提：数据库已初始化，相关环境变量已设置。以下命令从项目根目录启动，使上传资源路径与现有配置一致：

```bash
cd "解压目录的绝对路径" && mvn -f backend/pom.xml spring-boot:run
```

成功后后端接口位于 `http://localhost:8080/api`，终端会显示 Spring Boot 启动完成信息。

## 4. 启动 AI 服务

另开终端。建议使用独立虚拟环境，避免影响其他项目：

```bash
cd "解压目录的绝对路径/ai_service" && python -m venv .venv
cd "解压目录的绝对路径/ai_service" && .venv/Scripts/python -m pip install -r requirements.txt
cd "解压目录的绝对路径/ai_service" && .venv/Scripts/python app.py
```

以上为 Windows 命令；macOS/Linux 将 `.venv/Scripts/python` 换成 `.venv/bin/python`。安装成功后依赖保存在本地虚拟环境中，服务监听 `5000` 端口。OCR 依赖是可选项，安装方法见依赖清单；未配置智谱密钥时外部 AI 功能不可用。

## 5. 启动前端

再开终端：

```bash
cd "解压目录的绝对路径/frontend" && npm ci
cd "解压目录的绝对路径/frontend" && npm run dev
```

依赖安装完成后，浏览器访问终端显示的本地地址（默认 `http://localhost:5173`）。前端开发代理会连接 `8080` 端口的后端和 `5000` 端口的 AI 服务。

## 6. 测试与构建

项目当前没有前端、后端或 Python 自动化测试源码；`sql数据库/导入数据.sql` 是可重复生成演示数据的脚本，不属于单元测试。

```bash
cd "解压目录的绝对路径/backend" && mvn test
cd "解压目录的绝对路径/frontend" && npm run build
cd "解压目录的绝对路径/ai_service" && python -m compileall -q .
```

后端命令执行项目已有测试生命周期并编译源码；前端命令生成生产构建；Python 命令检查全部源码语法。构建生成的目录不包含在展示 ZIP 中，可由以上命令重新生成。
