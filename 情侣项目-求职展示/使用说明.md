# 情侣项目 · 求职展示源码包

## 项目简介

这是一个前后端分离的双人互动 Web 应用，包含登录与单设备会话、实时聊天、日记、爱情花园、音乐盒、头像与图片上传等功能。

- 前端：Vue 3、Vue Router、Vite、Axios、Socket.IO Client
- 后端：Python、Flask、Flask-SQLAlchemy、Flask-JWT-Extended、Flask-SocketIO
- 数据库：SQLite，首次启动自动建表并写入演示账号
- 前端版本：1.0.0（保留项目原有版本信息）

## 运行环境

- Windows 10 或 Windows 11
- Python 3.10+，并加入 PATH
- Node.js 18+ 与 npm，并加入 PATH
- 现代浏览器
- 首次启动需要网络，用于安装 Python 和 npm 依赖
- 仅当需要把非 MP3 音频转码为 MP3 时，才需要额外恢复 FFmpeg 工具

## 一键启动

双击根目录的 `一键启动.bat`。启动脚本会检查环境、补装缺失依赖、启动后端和前端，并打开浏览器。

- 页面地址：http://127.0.0.1:5173/
- 后端健康检查：http://127.0.0.1:5000/api/health
- 停止运行：关闭脚本打开的后端和前端命令行窗口

如果依赖安装失败，请检查网络和 Python/npm 的 PATH 配置后重新运行。

## 演示账号

全新数据库会自动创建两个本地演示角色，密码均为 `123456`：

这些是源码内置的公开演示账号，不是私人账号。可使用两个浏览器窗口分别登录，体验双人实时互动。

## 数据与本机目录

- 压缩包不包含原项目的本地数据库、聊天记录、上传文件、运行日志或授权数据。
- 首次启动会在后端目录重新创建空白 `app.db`。
- 上传目录默认是 `C:\upload`；可通过 `UPLOAD_BASE_FOLDER` 环境变量改为其他可写目录。
- 本地演示可通过 `JWT_SECRET_KEY` 环境变量设置随机密钥；源码中的默认值仅用于开发，不应用于公网部署。

## 非 MP3 音频转码

为符合“源码包不包含 EXE 成品”的要求，原项目附带的 FFmpeg 可执行文件未打入压缩包。页面访问、音乐播放和 MP3 上传不受影响；非 MP3 转码需要按以下步骤恢复：

1. 从 FFmpeg 官方或其可信发布渠道下载 Windows Essentials 构建。
2. 在 `couple-backend` 下创建 `ffmpeg-2025-04-23-git-25b0a8e295-essentials_build\bin` 目录。
3. 将发行包中的 `ffmpeg.exe` 和 `ffprobe.exe` 复制到该目录。
4. 重新启动后端。

项目当前代码使用上述固定相对目录，因此只把 FFmpeg 加入系统 PATH 不能替代这一步。
