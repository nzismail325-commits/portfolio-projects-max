# wb-proxy-max：多渠道 AI API 网关

面向求职展示的当前源代码快照，程序版本为 **1.0.0-max**。项目以 Python 标准库实现，将多个上游渠道统一为 OpenAI 兼容接口，并提供本地 Web 管理面板。

> 本包不包含真实账号、访问令牌、面板密码、个人配置或使用记录。真实上游联调需要使用者自行准备合法授权；离线测试不需要任何账号。

## 可展示的技术点

- 多渠道适配：WorkBuddy、Trae、Qoder、ZCode、CodeArts、Loomy，统一注册与面板能力声明。
- 协议转换：Chat Completions、Responses、模型列表，以及流式事件、工具调用和用量语义处理。
- 稳定性设计：账号池、并发槽、会话亲和、瞬时故障重试、流式保活和异常终止处理。
- 本地管理面板：账号、模型、任务、日志、用量、设置与上游更新状态。
- 隐私与安全：日志手机号脱敏、面板鉴权、API Key 校验、凭据静态加密相关实现。
- 可测试性：内置模拟上游和临时数据目录，覆盖核心协议与各渠道行为，无需真实服务。

## 运行环境

- 推荐 Windows 10/11；核心入口也可在其他支持 Python 的平台运行。
- Python 3.9 或更高版本；本次展示包使用 Python 3.10.11 验证。
- Python 运行与测试均只使用标准库，无需执行 `pip install`。
- Qoder 本地签名桥需要 Node.js，或可用的 Qoder 客户端运行时；桥接代码只引用 Node 内置模块，无需执行 `npm install`。
- 面板使用现代浏览器。前端为原生 ES Modules，本地已携带 Vue、Element Plus、样式和主题图片，无需前端构建。

## 快速启动

以下命令在解压后的 `wb-proxy-max-portfolio` 项目根目录执行。

```bash
python wb_proxy.py --host 127.0.0.1 --port 8788
```

启动后访问：

- 管理面板：`http://127.0.0.1:8788/`
- 健康检查：`http://127.0.0.1:8788/health`
- OpenAI 兼容接口：`http://127.0.0.1:8788/v1`

面板初始密码为 `admin`，首次登录后请立即修改。以上命令仅监听本机；不要在未设置独立 API Key 的情况下暴露到局域网或公网。

Windows 也可双击 `启动.bat`，或使用 `停止.bat` 停止对应服务。注意：该启动脚本当前默认启用局域网模式；求职评审和本地体验优先使用上面的本机监听命令。

## 运行测试

在项目根目录执行唯一冒烟测试入口：

```bash
python tests/test_smoke.py
```

测试会启动本地模拟上游，覆盖核心协议、流式响应、面板和各渠道行为。账号与运行数据均写入系统临时目录，成功时末尾输出：

```text
ALL CHECKS PASSED
```

项目没有独立构建步骤：Python 直接运行，前端静态文件由服务直接提供，也没有需要生成的缓存目录。

## 数据与公开配置

- 首次运行会自动使用或创建空的 `accounts/` 与 `usage/`；登录、设置、日志和用量数据只在使用者本机生成。
- `accounts/model.json` 是 models.dev 的可重建缓存，缺失时会按需异步刷新，不是启动前置条件。
- 输出上限探测结果会在执行探测后生成，不是启动前置条件。
- 当前程序版本、上游更新基线、更新检查与公告展示逻辑均保留在源代码中；本机的历史更新检查状态未带入。
- Trae 所需的公共设备公钥属于公开校验配置，已随当前源码保留；没有携带任何私人密钥。
- 第三方及上游许可说明见源码文件头与 `integrations/qoder_bridge/NOTICE.md`。

## 展示包边界

未包含 Git 元数据、旧版项目、上游只读快照、参考版本、EXE 成品、本机 Python/Node 依赖目录、浏览器与测试缓存、真实账号和设置、运行日志、用量数据库、联系方式或私人凭据。
